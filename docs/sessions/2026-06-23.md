## Aito quirks discovered

- **`$f` frequency aggregation is rejected** by the shared instance
  (`400 $f (of class java.lang.String)`) — despite the workbook
  instructions doc advertising it. Only `$mean/$min/$max` work. The
  instructions doc is misleading; cheatsheet was already correct.
- **Region values are lowercase** (`helsinki`, not `Helsinki`) — the
  capitalised form silently returns 0 rows / is ignored as a predict
  feature. Cost a workbook bug.
- **`_recommend` `where` conditions, it doesn't restrict candidates.**
  `where:{search_query:{$match:"food"}}` sets the *context*; Aito still
  ranks the whole `product_sku` domain, surfacing cold candidates via
  `basedOn` priors. Counting filtered rows ≠ recommend candidate set.
