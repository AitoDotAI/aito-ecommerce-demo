## Aito quirks discovered

- **`_search` ties come back in table order.** With BM25 and no word
  matched, every row is lift 1.0 and you get the head of the table.
  That made unmatched dog queries score as perfect answers in the eval
  until `$score == 1.0` rows were dropped.
- **`_evaluate` over `estimate` is documented but rejected.** The API
  spec lists `EvaluateEstimateQuery` (`mae`, `rmse`, `r2`); v2.10.3
  answers 400 "missing 'evaluate.predict'" on both v1 and v2. Routed to
  core.
- **`train` / `test` propositions work in `_evaluate predict`.** Training
  on the oldest month alone changes the score on the same test rows, so
  `train` is honoured.
- **`$p` selected alongside a `$multiply` orderBy is the whole product**,
  not a probability (values ≫ 1). Don't display it as one.
- **At the default θ 0.33, `$p` drowns `$similarity`** in a blend. A
  cat owner's "food for an old dog" returned cat food.
